# Graziele Maciel Beauty — site

Site estático (HTML, CSS e JS puros). Abra `index.html` no navegador.

## Como preencher
Todos os dados ficam em **`js/config.js`**:
- `whatsapp` — só números com 55 + DDD (ex: `5511999998888`)
- `tiktok` / `tiktokUser` — link e @ do TikTok
- `endereco` — endereço do perfil do Instagram (gera o mapa e o botão "Como chegar")
- `fotoPerfil` — salve a foto como `img/perfil.jpg`
- `galeria` — fotos mais virais: salve em `img/galeria/` e liste no array
- `videos` — cole links do TikTok, Instagram (reel) ou YouTube; o player é gerado sozinho
- `servicos` — nome e descrição de cada serviço

## Publicar
Funciona em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).
